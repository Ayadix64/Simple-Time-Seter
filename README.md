# Simple Time Seter
becuse why not?

This simpel ~200 line network app its job is seting you machine time to what ever benn in the server

To build ; if you just like me lazy to type the command; just run
``` bush 
make 
sudo make intall # if you want to install it to the bin folder
```

And to use it :

``` bash 
./sts server                  # to be the time server, this will take the port 6000
sudo ./sts cleint <server_ip> # and this to set the machine time to what ever was at the server
```
